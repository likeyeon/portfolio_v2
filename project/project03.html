구현 기능

  • window.matchMedia 함수로 화면 너비를 검사했을 때 991px을 초과하면 모바일 헤더가 자동으로 닫히게 하고, cleanup 함수를 통해 이벤트 리스너를 제거하여 성능 저하를 방지했습니다.

  • useLocation()을 사용하여 세부 카테고리 pathname에 해당하는 경우, 해당 메뉴 탭이 펼쳐지도록 구현했습니다.

  • react-helmet으로 페이지별 title을 설정하였습니다.
